# pizzas-sales-SQL-Analysis
SQL project analyzing pizza sales data to uncover insights on revenue, top‑selling pizzas, popular sizes &amp; categories, and sales trends. Includes queries for total revenue, rankings, and peak demand periods—helping optimize menu offerings and business decisions.
This project focuses on analyzing a pizza sales dataset using SQL to uncover valuable business insights. The dataset includes tables such as orders, order_details, pizzas, and pizza_types, which together provide a complete view of customer orders, product categories, and revenue streams.
The analysis is designed to answer key business questions:

Which pizza generates the highest revenue?

What are the most popular pizza sizes and categories?

What are the top 5 pizzas by quantity and revenue?

Objectives
Perform data exploration to understand the structure and relationships between tables.

Write SQL queries to calculate total revenue, identify best‑selling pizzas, and analyze order trends.

Generate rankings and insights that can help optimize menu offerings and improve sales strategies.

Tools & Technologies
SQL (MySQL) for querying and analysis

Dataset: Pizza sales records with detailed order information

Optional Tools: MySQL Workbench / VS Code for query execution

🚀 Outcomes
Clear breakdown of sales by category and size

Identification of top‑performing pizzas

Insights into peak sales periods and customer demand patterns
Actionable recommendations for menu optimization and business growth
